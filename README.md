# MarketOps - Entrega 2

Proyecto web estático de soporte técnico de supermercados.

## Para probar

Abre `index.html` mediante Live Server o publica la carpeta completa en Vercel. Selecciona el rol en el formulario de inicio de sesión.

- Administrador: crear, editar, eliminar, buscar y ordenar usuarios con Alpine.js.
- Encargado: filtrar equipos, crear reportes y revisar historial local.
- Técnico: ver sucursales, cambiar estados de equipos y consultar incidencias.
- PWA: manifest, iconos y service worker. Se debe verificar usando HTTPS o localhost.

Los datos son simulados. Las vistas de técnico y encargado usan `localStorage` del navegador para compartir cambios en la demostración; el administrador usa un arreglo en memoria. No hay conexión a base de datos ni autenticación real.
